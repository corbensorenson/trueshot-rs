# Security Policy

## Supported Revisions

Security fixes are made only on the latest revision of `main`. TrueShot has not
yet declared a production release or a long-term-support release.

## Reporting a Vulnerability

Do not disclose a suspected vulnerability in a public issue or discussion.
Use GitHub's private vulnerability reporting form:

<https://github.com/corbensorenson/trueshot-rs/security/advisories/new>

Include affected revisions, impact, reproduction steps, and any proposed
mitigation. Do not include private capture data, license keys, credentials, or
third-party personal data.

If private vulnerability reporting is unavailable, contact the repository
owner through GitHub without publishing exploit details.
