# Security Policy

## Supported Revisions

Security fixes are made only on the latest revision of `main`. TrueShot has not
yet declared a production release or a long-term-support release.

## Reporting a Vulnerability

Do not disclose a suspected vulnerability in a public issue or discussion.
Contact [@corbensorenson](https://github.com/corbensorenson) through GitHub and
request a private reporting channel without including exploit details.

In the private report, include affected revisions, impact, reproduction steps,
and any proposed mitigation. Do not include private capture data, license keys,
credentials, or third-party personal data.
